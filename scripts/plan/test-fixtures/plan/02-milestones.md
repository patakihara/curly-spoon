## Milestones

Each milestone is a slice that runs end to end.

### M0 · Foundations

- **[M0.aa]** The first item, with **bold** words.
  _Done when:_ (a) a test asserts the first thing works end to end; (b) a test asserts the second thing works end to end.
- **[M0.bb]** The second item.
  _Done when:_ (a) a test asserts the second item works end to end.
- **[M0.cc]** The third item.
  _Done when:_ (a) a test asserts the third item works end to end.
- **[M0.dd]** The fourth item.
  _Done when:_ (a) a test asserts the fourth item works end to end; (b) Sofia's sign-off.

**[M0.exit] Done when** you sign in and it works.
_Done when:_ (a) Sofia's sign-off.

### M1 · It plays

- **[M1.play]** Playback works.
  _Done when:_ (a) a test plays a recorded book end to end.

**[M1.exit] Done when** you listen for a week.
_Done when:_ (a) Sofia's sign-off.

### M2 · My library

- **[M2.lib]** The library shows.
  _Done when:_ (a) a test lists every recorded book and album.

**[M2.exit] Done when** you find anything fast.
_Done when:_ (a) Sofia's sign-off.

### M3 · Play or get anything

- **[M3.get]** Getting works.
  _Done when:_ (a) a test requests a recorded album and gets it.

**[M3.exit] Done when** any song plays.
_Done when:_ (a) Sofia's sign-off.

### M4 · Browse like Spotify

- **[M4.browse]** Browse recommends.
  _Done when:_ (a) a test builds a shelf from recorded history.

**[M4.exit] Done when** Browse finds you something.
_Done when:_ (a) a test replays history and scores the shelf; (b) Sofia's sign-off.

### M5 · Everywhere, polished

- **[M5.polish]** Polish everywhere.
  _Done when:_ (a) a test compares every screen to its canvas render.

**[M5.exit] Done when** Spotify is uninstalled.
_Done when:_ (a) Sofia's sign-off.

### M6 · Later, and separate

- **[M6.later]** Something for later.
  _Done when:_ (a) a test does the later thing end to end.
