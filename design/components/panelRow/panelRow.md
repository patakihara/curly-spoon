# panelRow

A heading line in a back-layer panel (Sort by, Genre…). Visuals: font = the subtitle token (mono), 11px, no case transform, 80% opacity.

Its content slot holds the row's controls, side by side, sharing the width, below the heading (gap: 12 between the heading and
the controls and between controls). The heading is optional: a More's rows have none (its bar names the param). Variant place: panel (the default; chip rows wrap) or controls (a back layer's controls row,
hire controlsRow: no heading, chip rows scroll); wrapOptions follows it.
