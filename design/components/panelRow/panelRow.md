# panelRow

A heading line in a back-layer panel (Sort by, Genre…). Visuals: font = the subtitle token (mono), 11px, no case transform, 80% opacity.

Its content slot holds the row's controls, side by side, sharing the width, below the heading (gap: 12 between the heading and
the controls and between controls). The heading is optional: a More's rows have none (its bar names the param). wrapOptions:
chip rows in a panel row wrap instead of scrolling.
