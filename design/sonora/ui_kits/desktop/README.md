# Desktop UI kit

Click-through recreation of the desktop/web player. Sidebar navigation uses the same Material Symbols vocabulary as the mobile kit — Search, Browse, Music, Books, Podcasts — and each page matches the mobile equivalent in structure.

Screens: **Browse** (search field, 6 quick tiles in a fixed 3×2 grid, "Most played" carousel), **Music** / **Books** / **Podcasts** (album-grid pages), **Album detail** (header + track list), plus the persistent three-column player bar and a collapsible queue panel toggled from it.

Open `index.html`. Click sidebar items to switch views; click play/pause in the player bar.
